# Culturally-Grounded-MIR


**Culturally-Grounded-MIR** is a curated, open-source library of research papers, datasets, and computational models dedicated to the analysis and generation of non-Western and folk music traditions.

Standard MIR algorithms often rely on assumptions from Western tonal music (12-tone equal temperament, harmonic focus). This repository centralizes research that tackles the unique challenges of global music systems, including **microtonality**, **non-isochronous rhythms**, **modal evolution**, and **oral traditions**.
